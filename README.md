# 進路 SHINRO · 日本计算机修士择校工具

面向从中国准备赴日参加计算机相关修士考试的择校工作台。按**具体项目＋选拔路径＋入学批次**筛选和比较，附官方来源、资料年度、页面定位和待核实项。

## 功能

- 按考试科目、研究方向、地区、入学期、考试形式、英语成绩类型和导师联系要求组合筛选。
- 区分必答与选答；排除不想准备的科目时，检查是否仍存在可行选答组合。
- 单独处理未知、部分未知的口试范围，不将“待核实”当作“免考”。
- 按预计取得本科学位日期检查普通学历路径的时间冲突。
- 收藏候选项目、设置考虑优先级、记笔记、跟进待核实事项。
- 横向比较2–4条路径，支持只看差异、导出CSV。
- 个人记录保存在当前浏览器，支持JSON备份和合并恢复。

## 本地运行

需要 Node.js 22 或以上，无第三方依赖，无需安装依赖。

```bash
npm start
```

打开终端显示的 `http://127.0.0.1:5173`。可用环境变量 `PORT` 更换端口。

```bash
npm run check
npm test
```

也可使用其他静态HTTP服务器，将 `dist/` 设为网站根目录。请通过HTTP访问，避免直接双击HTML导致ES模块加载失败。

## 数据范围与限制

首版收录8所大学、10条2027年入学选拔路径：东京大学、京都大学、大阪大学、名古屋大学、九州大学、筑波大学、NAIST、JAIST。筑波与NAIST分别区分春季/秋季入学。

资料于 **2026-10-26** 核验，均可追溯至大学官方网页或PDF。已截止批次保留作备考参考；2027规则不直接推断为2028规则。研究方向标签由官方研究主题归纳，不承诺导师当期名额。筛选结果不代替个人资格审查。

本项目没有自动刷新招生数据或跨设备同步。正式出愿前，须重新检查当期要项、学校更正公告、海外学历预审、导师接收、语学成绩格式和手续日期。

## 目录

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 网站页面入口 |
| `dist/style.css` | 响应式样式 |
| `dist/app.mjs` | 交互、比较、导出与浏览器本地记录 |
| `dist/data.mjs` | 项目数据、官方来源与定位 |
| `dist/engine.mjs` | 科目/选答组合、日期与筛选逻辑 |
| `tests/filters.test.mjs` | 主要筛选逻辑验证 |
| `scripts/serve.mjs` | 无依赖本地静态服务器 |

## 维护数据

修改 `dist/data.mjs` 前先阅读目标年度、目标选拔路径的官方原文。更新来源链接、适用年度、页码/章节定位及核验日期；保留未核实字段。界面中的核验日期文字也应一并更新。
